# 双X六击显示修复记录

**日期**: 2025-10-21  
**问题**: 当天地盘都是同一个天干时，显示"X六击"而不是"双X六击"

## 问题描述

在时间202509120800中：
- 离9宫：天盘['辛']、地盘['辛'] -> 午位应显示"双辛六击"
- 坤2宫：天盘['己']、地盘['己'] -> 未位应显示"双己六击"  
- 震3宫：天盘['戊']、地盘['戊'] -> 卯位应显示"双戊六击"

但实际显示的是"辛六击"、"己六击"、"戊六击"。

## 根本原因

在修复天地盘同干检测后，算法为每个配对只生成1个标注。当天盘有1个天干、地盘也有1个同样的天干时：
- 配对数 = min(1, 1) = 1
- 只生成1个标注："X六击"
- 但这种情况应该理解为"天地盘各1个，即双X"，应显示"双X六击"

## 修复方案

修改 `core/paipan_engine.py` 的 `_analyze_liu_ji_structured` 方法，增加判断逻辑：

```python
# 判断是否显示"双X六击"：
# 当配对数为1且天地盘各只有1个该天干时，显示"双X六击"
# 当配对数>=2时，每个配对都显示"X六击"，后续会被合并处理
is_single_pair = (ji_xing_count == 1 and tian_pan_count == 1 and di_pan_count == 1)

if is_single_pair:
    # 天地盘各1个，显示"双X六击"
    annotations[target_zhi].append({
        "type": "liuji",
        "text": f"双{gan}六击",
        "strike": False
    })
else:
    # 其他情况按配对数生成标注
    for _ in range(ji_xing_count):
        annotations[target_zhi].append({
            "type": "liuji",
            "text": f"{gan}六击",
            "strike": False
        })
```

## 语义解释

"双X六击"的含义：
- **双**：指天盘和地盘各有1个该天干（天地成双）
- **X**：具体的天干（戊、己、庚、辛、壬、癸）
- **六击**：六仪击刑的简称

这符合奇门遁甲术语中"双X"的传统表述方式。
