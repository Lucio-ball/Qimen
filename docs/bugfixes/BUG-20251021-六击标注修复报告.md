# 六击标注BUG修复报告

**日期**: 2025-10-21  
**版本**: v1.2.3 (待发布)  
**修复者**: GitHub Copilot

## BUG描述

### 问题现象
在时间202509120800中发现以下问题：
1. 离9宫天地盘天干均为辛，但**午位没有显示辛击刑标注**
2. 坤2宫天地盘天干均含己，但**未位没有显示己击刑标注**

### 根本原因
在`core/paipan_engine.py`的`_analyze_liu_ji_structured`方法中，算法错误地将天盘干和地盘干**合并后统计总数**，而不是检查天地盘是否**同时存在该天干**。

#### 错误代码（修复前）
```python
# 合并天盘干和地盘干
all_gan_list = tian_pan_stems[gong] + di_pan_stems[gong]

# 统计该干支的出现次数
gan_count = all_gan_list.count(gan)

if gan_count > 0:
    # 根据出现次数生成对应的标注
    for _ in range(gan_count):
        annotations[target_zhi].append({
            "type": "liuji",
            "text": f"{gan}击刑",
            "strike": False
        })
```

**问题分析**：
- 这种统计方式会在天盘或地盘**单独**存在该天干时也生成标注
- 但六仪击刑的正确条件是：**天盘和地盘同时存在该天干**（天地盘同干）

## 修复方案

### 1. 算法修正
修改`_analyze_liu_ji_structured`方法，分别统计天盘和地盘中该天干的次数，只有当两者都大于0时才标注：

```python
# 统计天盘和地盘中该天干的出现次数
tian_pan_count = tian_pan_stems[gong].count(gan)
di_pan_count = di_pan_stems[gong].count(gan)

# 只有当天盘和地盘中都存在该天干时才标注六击
if tian_pan_count > 0 and di_pan_count > 0:
    # 六击标注次数为天地盘中较小的次数（对应的配对数）
    ji_xing_count = min(tian_pan_count, di_pan_count)
    
    # 根据配对次数生成对应的标注
    for _ in range(ji_xing_count):
        annotations[target_zhi].append({
            "type": "liuji",
            "text": f"{gan}六击",
            "strike": False
        })
```
