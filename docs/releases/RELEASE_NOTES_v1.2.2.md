# 奇门遁甲工作台 v1.2.2 发布日志

**发布时间**: 2025年9月24日  
**版本号**: v1.2.2  
**发布代号**: RELEASE-20250924-001

## 🎯 主要更新

### 1. 天干长生状态显示优化
- **显示字符优化**: 冠带状态现在显示为"带"（原为"冠"）
- **颜色分级系统**: 引入能量强弱的颜色分级
  - **天干十二长生** - 三色分级：
    - 🔴 能量强（红色）：长生、临官、帝旺
    - 🟡 能量一般（黄色）：沐浴、冠带、胎、养
    - ⚫ 能量差（灰色）：衰、病、死、墓、绝
  - **旺相休囚死** - 两色分级：
    - 🔴 能量强（红色）：旺、相
    - ⚫能量差（灰色）：休、囚、死、废

### 2. 值使门落宫算法重大修复 🔧
- **问题修复**: 修正了"值使随时宫"算法的致命错误
- **核心改进**: 
  - 正确实现值使门跟随当前旬值班军队的逻辑
  - 修复了阴遁局中值使门位置计算错误
  - 确保死门等值使门落在正确宫位（如巽4宫而非坎1宫）
- **算法原理**: 
  1. 以当前旬值班军队在地盘的位置为初始点
  2. 根据时支与旬支差值进行位置调整（阳顺阴逆）
  3. 处理中5宫寄生到坤2宫的特殊情况
  4. 从确定位置顺时针排布八门

### 3. 击刑标注算法优化
- **多重标注处理**: 改进了同一干支多次出现时的击刑标注逻辑
- **显示优化**: 根据干支出现次数自动生成对应数量的击刑标注
- **用户体验**: 提高了标注系统的准确性和可读性
