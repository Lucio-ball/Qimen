# 奇门遁甲工作台 v1.2.4 发布说明

## 📅 发布信息
- **版本号**: v1.2.4
- **发布日期**: 2025年10月22日
- **发布代号**: RELEASE-20251022-001

## 🎯 本次更新重点

### 核心修复：节气算法重大升级

本次更新完全重构了节气计算算法，从之前基于 `pyplanets` 库的天文计算切换到**中国科学院紫金山天文台官方数据**，彻底解决了节气计算偏差问题。

## 🔧 详细更新内容

### 1. 节气算法修复 🌟

**问题描述**:
- 用户报告：2025年9月7日14:13显示为"白露"，但应该是"处暑"
- 根本原因：pyplanets 库计算的太阳黄经与官方数据存在约2.7小时偏差

**解决方案**:
- ✅ 采用中国科学院紫金山天文台发布的**官方节气数据**
- ✅ 2025年全年24节气精确到秒级
- ✅ 白露交节时间：2025年9月7日 16:54:41（北京时间）

**测试验证**:
```
✓ 2025-09-07 14:13      -> 处暑 (修复成功！)
✓ 2025-09-07 16:54:40   -> 处暑 (白露前1秒)
✓ 2025-09-07 16:54:41   -> 白露 (精确交节时刻)
✓ 2025-09-07 17:00      -> 白露 (白露后)
✓ 2025-09-12 08:00      -> 白露 (其他测试通过)
```

**技术细节**:
- 数据来源：中国科学院紫金山天文台
- 精度等级：秒级精度
- 覆盖范围：2025年完整年份
- 向后兼容：100% API兼容

### 2. 文件更新

**修改的文件**:
- `core/calendar_utils.py` - 节气算法核心文件（完全重写）
- `ui/widgets/welcome_widget.py` - 更新版本显示为 v1.2.4
- `ui/dialogs/preferences_pages.py` - 更新版本号为 v1.2.4
- `requirements.txt` - 添加 skyfield 库（为未来扩展预留）

**新增的文件**:
- `docs/bugfixes/BUG-20251022-001-节气算法修复报告.md` - 详细技术文档
- `tests/test_2025_jieqi_official.py` - 2025年节气完整测试
- `tests/test_jieqi_202509071413.py` - 原问题测试用例
- `tests/test_solar_longitude.py` - 太阳黄经计算测试
