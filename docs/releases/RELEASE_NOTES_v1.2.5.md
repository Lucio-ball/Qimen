# 奇门遁甲工作台 v1.2.5 发布说明

## 📅 发布信息
- **版本号**: v1.2.5
- **发布日期**: 2026年1月19日
- **发布代号**: RELEASE-20260119-001

## 🎯 本次更新重点

### 核心修复：节气算法口径统一为“交节时刻”

本版本将节气计算**统一切换为 `sxtwl`（天文历算）**，以“交节时刻”为唯一合法边界，满足命理用途（八字/月令/起运）对节气边界的严格要求。

## ✅ 节气判定规则（本版本口径）

- **时间标准**：北京时间（UTC+8）
- **精度**：秒级
- **判定区间**：
  - 上一个节气交接时刻 ≤ 当前时间 < 下一个节气交接时刻
- **交节瞬间**：交节秒点归属**新节气**
- **跨年边界**：正确处理（例如冬至→小寒→大寒→立春等）

## 🔧 详细更新内容

### 1. 节气算法实现替换（重要）

- ✅ 移除旧的固定表/近似推算逻辑，统一使用 `sxtwl.getJieQiByYear()` 获取交节时刻
- ✅ 内部实现按“交节点列表 + 二分查找”判定所属节气
- ✅ 缓存相邻年份交节点，确保跨年区间判定稳定

相关文件：
- `core/calendar_utils.py`
